# Jak wgrać mody 

1. Pobierz potrzebny Ci pakiet:

| Pakiet    |                                                       Link do pobrania                                                       |
| ---------- | :--------------------------------------------------------------------------------------------------------------------------: |
| Actions    |  [Pobierz](https://dbm-network.github.io/download-git/#/home?url=https://github.com/nowehity97/dbm/tree/main/actions)       |
| Raw Data     |   [Pobierz](https://dbm-network.github.io/download-git/#/home?url=https://github.com/nowehity97/dbm/tree/main/rawdata)   |

2. Klikamy w dbm ``Project`` ->  ``Open Project Directory``
3. Wypakuj zawartość pliku .zip do folderu, który właśnie otworzyłeś Actions.zip do katalogu Actions w plikach bota
   (Nadpisz istniejące pliki, jeśli zostaniesz o to poproszony)
4. Aby wgrać rawdata do bota tworzymy nową komendę i klikamy prawym ``edit raw data`` usuwamy wszytko i wklejamy zawartość pliku / lub kopiujemy rawdatę z repo
